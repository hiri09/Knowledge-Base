# Section 4 — Reading a chart

Deliberately short, and deliberately after fundamentals. A chart tells you about
other people, never about the business.

1. `charts-basics.md` — candles, trend, support/resistance, volume, moving averages
2. `why-technicals-mislead-beginners.md` — read this one twice

**Do in the lab after this:** open `../lab/trading-lab.html`, press `L` to mark a
support level *before* price reaches it, then step bar by bar with the arrow key.
Then run the "Pure random walk" scenario and try to find patterns in it.

**Done when** you use charts for stops and sizing, and never to pick what to own.
