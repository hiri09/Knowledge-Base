all. Per the Reviewer's own hard rule, **one video is noise** — nothing gets
promoted to standing lessons until a pattern repeats across 3+ uploads. Writing
"research failed" off this single number would teach the system the wrong
lesson and change the one thing that is probably right.

**The honest read if it underperforms:** suspect the hook and the first three
seconds first, then packaging, then the story — in that order, because that is
the order of how much each one moves a Short.
